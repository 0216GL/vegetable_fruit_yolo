## 〇、先回答一个问题：这是给公司做需求吗？

**不是。**

老师说的"面向农业公司"是**定位问题**——你在说"我的用户是谁"。不是"有个客户在等你交付"。

所以：

- **没有真实客户**，没有人在催你
- **需求是你自己从调研里推出来的**（下面第三节给了原料）
- **做错了不会赔钱**，这正是你练手设计的最好时机

这也是你第一次真正做"设计"。以前你是接需求，现在你要出需求。

## 一、设计和实现的区别

| | 实现（你以前做的） | 设计（现在要练的） |
|---|---|---|
| 输入 | 别人给你"要做什么" | **你自己搞清楚"要做什么"** |
| 你的工作 | 想"怎么做" | 想"做什么" + "怎么做" |
| 难在哪 | 技术 | **判断什么该做、什么不该做** |

**设计的第一步永远不是想表，是想人。** 想清楚人拿它干什么，表会自己浮出来。

---

## 二、七个步骤（照着走）

```
1. 写场景      谁、在什么情况下、想干什么、得到什么
2. 挑名词      从场景里圈出名词 → 候选实体
3. 定字段      每个实体有哪些属性
4. 定关系      谁和谁是一对多、多对多
5. 列操作      哪些是读、哪些是写
6. 回头看      哪个操作数据量最大/最慢 → 索引和冗余字段
7. 画表写码    到这一步才开始写 SQL
```

**注意第 6 步。** 新手设计最容易漏的就是这里——表和字段谁都能想出来，
真正区分水平的，是"我知道这个查询以后会慢，所以提前加了索引/留了冗余字段"。

## 三、先看一个完整的例子（图书借阅）

用**别的领域**举例，免得我直接给你答案。你把它当模板，套到我们项目上。

### 第 1 步：写场景

> 学生拿着一本书到柜台，管理员扫码登记。系统要记住"谁、什么时候、借了哪本、什么时候该还"。
> 还书时再扫一次，记录实际归还时间。

### 第 2 步：挑名词

圈出来：**学生**、**书**、**借阅记录**、**管理员**

→ 候选实体：学生、书、借阅记录

（"管理员"暂不建表——他只是一个操作者，不做权限的话不用记录他是谁）

### 第 3 步：定字段

```
学生      id, 学号, 姓名
书        id, ISBN, 书名
借阅记录   id, 学生id, 书id, 借出时间, 应还时间, 实还时间
```

### 第 4 步：定关系

- 一个学生 → 多条借阅记录（一对多）
- 一本书 → 多条借阅记录（一对多）
- 所以**借阅记录是学生和书之间的"多对多"中间表**

> 💡 这是数据库设计里最常见的一个模式：**两个实体多对多 → 中间表**。
> 而且中间表往往还会带上"关系自己的属性"（借出时间、应还时间）。

### 第 5 步：列操作

| 操作 | 读/写 |
|---|---|
| 借书 | 写 |
| 还书 | 改 |
| 查某个学生借了哪些书 | 读 |
| 查某本书被谁借过 | 读 |
| 查所有逾期未还的 | 读（带条件） |

### 第 6 步：回头看（★ 这一步最见功力）

- "查某个学生借了哪些书" → 每次都要按学生找 → **`学生id` 建索引**
- "查逾期未还" → 要按应还时间筛 → **`应还时间` 建索引**
- 借阅记录表会**越长越大**（每天几百条），但这三个索引能让查询一直很快

### 第 7 步：这才开始写 SQL

## 四、原料：我们的项目

### 我们已经推出来的需求（推断自调研，不是客户给的）

| # | 需求 | 来源 |
|---|---|---|
| R1 | 记录一次巡检：地块、时间、照片、识别出的每颗果 | 基本功能 |
| R2 | 查看某次巡检的详情（逐颗果实的成熟度） | 基本功能 |
| R3 | **按加工用途统计**：这批果里多少适合做柿饼、多少适合酿醋 | ★ 老师那句"不同农副产品需要不同成熟度" |
| R4 | **看历史趋势**：同一片林子，这周比上周熟了多少 | 采收决策需要 |
| R5 | 提醒什么时候该采 | ❌ **这次不做**（要预测，太远） |

**R3 是新的，以前的旧设计里没有。** `docs/ARCHITECTURE.md` 第五节里那份表结构是 10-02 写的，
那时还不知道"按用途选果"这件事，所以它已经**部分过时**了。别照抄。

### 场景（照这个写第 1 步）

> 合作社/农业公司的技术员到一片柿子林，掏出手机拍几张照片。
> 系统告诉你：这片林子有 115 颗果，其中 41 颗适合做柿饼、18 颗适合酿醋、56 颗还太生。
> 下周他再来拍一次，系统告诉你熟了多少。
> 采收季到了，他打开历史记录，看这片林子的成熟度是怎么推进的，决定哪天开摘。

### 可能的名词（我不给全，你自己圈）

地块 / 巡检 / 果实 / 成熟度 / 用途 / 照片 / 时间 / 用户 / 果园 / 柿饼 / 醋 ……

**里面有些该建表，有些不该。这就是第 2 步要你判断的。**
