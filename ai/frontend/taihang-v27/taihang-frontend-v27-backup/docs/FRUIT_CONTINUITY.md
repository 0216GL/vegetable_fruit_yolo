# Whole fruit and home continuity

Changes after editorial version:

- Removed the whole/cut persimmon photograph from the third screen, photo credits and deployment assets. Replaced that view with the existing genuine whole-persimmon alternate angle. Its label/alt text now describe complete fruit. The slider, four stages, original color switch, magnifier and mobile detail implementation are untouched.
- Home second screen no longer uses a bright wall photograph or notebook image popups. It keeps the opening's blue-grey boundary (#102e30), a short low-opacity atmospheric transition, and three stable photographic views: persimmon, apple, pear. Edges dissolve into the common field; pointer response is restrained. Buttons select observation notes rather than opening or enlarging pictures.
- Apple and pear are explicitly presented as extension directions, not supported maturity-inference classes. Different cultivars must not inherit persimmon labels.
- Removed the Roots photograph-enlarge button; retained decoded perspective selection and content accordion.
- Project archive keeps its existing preview graphs and opens text-only dossier explanations, not enlarged images.
- First-screen animation, recognition workbench and robot retained without source changes.
