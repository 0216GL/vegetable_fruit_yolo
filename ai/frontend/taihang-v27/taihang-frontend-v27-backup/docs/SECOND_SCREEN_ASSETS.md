# 首页内容与素材

首页顺序：已定稿的山野开场 → 四级分级与检测入口 → 山渠与果园 → 小禾引导。首页和识别页均不再使用窗户场景。

第二屏的实物照片：`dist/assets/persimmon.webp`，原有 Unsplash 摄影。分级选择只展示色泽线索，不提供模型识别结果，不视为标注数据。入口连接 `#recognize`，直接显示现有上传与本地预览工作台。

用户新提供的竖幅图：`dist/assets/taihang-valley-story.jpg`。用于首页第三段山渠缘起，保留竖幅取景，不做全屏背景、拼接或形变。本图仅标为用户提供的山野意境图，未声称为项目实拍或红旗渠实景。高清替换时覆盖该文件，并按新尺寸更新 home() 中图片的 width/height；手机取景由 `.origin-story img` 管理。

开场动画、燕子、首页主景、小禾形象与动作、上传处理代码继续保留。
