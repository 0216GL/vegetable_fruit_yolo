# 小禾观察手记

基于“三次”原站版本54继续修改，实验站和原版备份均未覆盖。

小禾保持原有角色与分层眨眼、呼吸、点击回应，新增独立的柔和2.5D纸景背景、纸页叠层、鼠标微视差与三个观察主题。支持方向键切换主题，原生色带探索四级外观颜色；本屏不执行检测。

背景素材：dist/assets/he-atelier-paper.webp。内置imagegen生成，提示为低饱和暖灰与鼠尾草绿的纸艺观察空间，左侧留白用于真实HTML，右侧保留角色位置、植物、柿子与观察本，无文字无UI无人物；轻柔日光、接触阴影、微纸纹，不使用窗框。角色、背景和界面分别管理。

燕子：开场先留出1.5秒建立山景；从左侧屏外进入，平滑调整尺度与透明度，沿上升曲线远去，减弱近景骤大。首页山景、柿子、开场镜头与其余时间轴保持原样。

验收：桌面与手机主题切换、键盘切换、色带、角色回应、助手打开、阅读与检测入口；减少动态效果时取消视差。
