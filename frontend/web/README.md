# 太行果眸 · 前端备份 v27

这是 2026 年 10 月 22 日当前已上线版本的完整前端备份，保存于进一步修改第三页第二屏之前。

## 文件

- `dist/index.html`：网页入口。
- `dist/assets/`：页面脚本、样式、图片及素材来源说明。
- `docs/`：后端对接与历史改动说明，部分文档描述历史版本，以实际代码为准。
- `SOURCE_VERSION.json`：本备份对应的源代码版本。
- `SHA256SUMS.txt`：文件校验值。

## 运行

无需安装依赖或构建。在本文件夹打开终端，执行：

```sh
python -m http.server 8080 --directory dist
```

然后在浏览器访问 `http://localhost:8080`。

## 与后端结合

将本文件夹内容上传到你们的 GitHub 分支，后端优先阅读 `docs/BACKEND_INTEGRATION.md`。当前真实检测服务仍待接入，预设示例不代表真实模型结果。上传图片当前仅在浏览器本地预览。

## 备份范围

包含首页开场与三屏、识别页、山渠页、项目页及小禾动作。没有在备份过程中修改线上网站。

未包含 Git 历史、授权信息和原站托管身份配置；可在自己的仓库或服务器部署 `dist/`。素材许可见 `dist/assets/photography-sources.html`。
