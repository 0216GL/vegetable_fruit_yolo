关于这张预览里的两个替身。 一、图片是 SVG 示意图，不是真实照片 —— 为了在离线预览里把"果实 + 标注框"的构图表达清楚。 真正跑起来时这里是果园实拍图，框的位置由后端返回的坐标算出来。 二、数字的字体不是设计里指定的 Barlow（离线加载不了外部字体），会退到系统字体。

这个页面能验证什么：配色关系、信息层级、"英雄区是图不是数字"这个判断、 色带的三重编码（色块 + 名称 + 数量）、以及深浅两个面用的是同一套语义令牌。
