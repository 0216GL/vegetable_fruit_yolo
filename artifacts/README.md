## 怎么复现

不需要重跑模型，用现在的模型直接推理即可（在项目根目录执行）：

```bat
D:\Anaconda\envs\yolo\python.exe -m ai.detect "artifacts\新测试图_第二轮\2_(103).jpg"
```

结果图会存到 `runs/detect_predict/`。
